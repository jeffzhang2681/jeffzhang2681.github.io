# Personal Website

Jeff Zhang's personal website — a place to introduce myself, share my background,
and highlight my work at [Tatari](https://www.tatari.tv).

## Goal

This site is meant to give visitors a quick, clear picture of who I am:

- **About me** — background, interests, and how I got here
- **Work at Tatari** — my role, the problems I work on, and projects I'm proud of
- **Contact** — how to get in touch

## Status

A single-page static site (plain HTML/CSS/JS, no build step) with About,
Work, and Contact sections.

## Roadmap

- [x] Build the About / Tatari / Contact sections
- [ ] Deploy the site (e.g., GitHub Pages)
- [ ] Iterate on design and content

## Development

No build step required. To preview locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.
